# ⚽ מאמן פנדלים

אפליקציית ווב שמנתחת בעיטת פנדל של ילד ונותנת לו משוב קולי בעברית: מה היה טוב, מה לשפר, ועל מה לשמור.
ילד אחד מצלם, השני בועט. האפליקציה מכוונת את המצלם למקום הנכון, מתחילה להקליט לבד, מזהה את רגע הבעיטה ומנתחת את התנועה.

הכול רץ בטלפון. הסרטונים לא נשלחים לשום שרת.

## איך זה עובד

1. **כיוון המצלמה** – זיהוי שלד (MediaPipe Pose) וזיהוי כדור (EfficientDet) בזמן אמת. האפליקציה בודקת:
   טלפון לרוחב, הילד כולו בתמונה, מרחק, כדור, מקום לריצה ולהמשך הבעיטה, צילום מהצד, טלפון ישר ויציב, תאורה.
   ההוראות מוצגות עם חצים ונאמרות בקול ("זוז קצת ימינה", "התרחק 2–3 צעדים"…).
   אם הכדור לא מזוהה – מקישים עליו במסך.
2. **הקלטה אוטומטית** – כשהכול ירוק שנייה אחת נשמע "מוכן! אפשר לבעוט". ההקלטה נעצרת לבד שנייה אחרי הבעיטה.
3. **ניתוח** – שישה מדדים, ביחידות של אורך הרגל של הילד (כך שהמרחק מהמצלמה לא משנה):

| מדד | מה נמדד |
|---|---|
| ריצת תנופה | המרחק מהכדור בתחילת הריצה |
| הנפת רגל הבעיטה | כמה הברך מתכופפת בהנפה לאחור |
| מיקום רגל התמיכה | איפה רגל התמיכה ביחס לכדור ברגע הבעיטה |
| ברך רגל התמיכה | כפופה קלות, לא נעולה |
| הטיית הגוף | מעל הכדור או נשען אחורה |
| המשך תנועה | האם הרגל ממשיכה לכיוון המטרה |

4. **משוב** – כרטיסים על המסך + הקראה בעברית, וצפייה חוזרת פריים-פריים עם השלד מצויר.

אפשר גם **לנתח סרטון מהגלריה** – מומלץ לצלם בהילוך איטי (Slo-mo) במצלמה הרגילה של הטלפון ולהעלות. בדפדפן ההקלטה החיה היא בערך 30 פריימים לשנייה.

## התקנה ב-GitHub Pages

1. Settings ← Pages ← Source: **Deploy from a branch**, Branch: `main`, תיקייה: `/ (root)`.
2. אחרי דקה-שתיים האתר זמין ב: `https://<user>.github.io/<repo>/`
3. בטלפון: פותחים את הכתובת ← "הוסף למסך הבית" כדי שייפתח כמו אפליקציה.

המצלמה עובדת רק ב-HTTPS, ו-GitHub Pages נותן את זה אוטומטית. בפעם הראשונה נטענים המודלים (כ-15MB), אחר כך הם שמורים בטלפון.

## כוונון

כל הספים נמצאים ב-`js/config.js` (למשל טווח "טוב" למיקום רגל התמיכה או להטיית הגוף).
בהגדרות האפליקציה אפשר להפעיל **"הצג נתונים טכניים"** כדי לראות את המספרים בזמן הצילום.

## מבנה

```
index.html          מסכים: בית, מצלמה, עיבוד, תוצאות, הגדרות
css/style.css
js/app.js           בקר ראשי: מצלמה, הקלטה אוטומטית, תוצאות
js/vision.js        טעינת MediaPipe, זיהוי שלד וכדור
js/framing.js       עוזר הכיוון (פונקציה טהורה)
js/analyze.js       ניתוח הבעיטה (פונקציה טהורה)
js/feedback.js      טקסטים של המשוב (בן/בת)
js/speech.js        הקראה בעברית
js/sensors.js       ג'ירוסקופ – טלפון ישר ויציב
js/draw.js          ציור שלד וסימונים
js/store.js         הגדרות והיסטוריה (בטלפון בלבד)
sw.js, manifest.json  PWA
tests/              בדיקות לוגיקה עם בעיטות סינתטיות: node tests/run-tests.mjs
```

## מגבלות ידועות

- הצילום הוא דו-ממדי מצד אחד, ולכן המדידות הן הכוונה ולא שיפוט מדויק. חשוב לצלם מהצד.
- כיוון הבעיטה לפינה, וחלק הרגל שפוגע בכדור, לא נמדדים בגרסה הזו.
- קול עברי: באנדרואיד צריך שיהיה מותקן קול עברית ב-Google TTS. באייפון יש קול מובנה.
- באייפון צריך לאשר גישה לחיישני תנועה בלחיצה הראשונה (בשביל בדיקת "טלפון ישר").
